# 使用说明

## 启动

UDaSnap 是菜单栏应用，不显示 Dock 图标。启动后菜单栏出现图标；首次启动会显示欢迎与隐私说明，同意《隐私政策》和《用户协议》后才能继续。

首次截图前，需要在“系统设置 → 隐私与安全性 → 屏幕录制”中允许 UDaSnap，并重新打开应用。滚动截图的自动滚动、“强力模式”和全局热键需要辅助功能权限。

## 快捷键

| 功能 | 默认快捷键 | 备用键 | 说明 |
|---|---|---|---|
| 截图并贴图 | `⌃⇧4` | `⌥⇧4` | 框选后生成置顶浮窗 |
| 框选截图 | `⌃⇧5` | `⌥⇧5` | 复制并保存，不贴图 |
| 应用窗口截图 | `⌃⇧3` | `⌥⇧3` | 点选一个窗口，带原生阴影 |
| 滚动截图 | `⌘F4` | `⌥⇧6` | 框选滚动区域，自动拼接长图 |
| 文字提取 | `⌃⇧2` | `⌥⇧2` | Vision OCR，结果可编辑 |

备用键固定不可录制。五个主热键都可以在“偏好设置 → 快捷键”中重新录制；被其他应用占用时可打开“强力模式”。标注没有全局热键。

菜单栏还提供：

- **标注截图**：位于“文字提取 - AI 分析”下面，子菜单含“框选标注 / 窗口标注 / 全屏标注”；三项都不占热键。
- **全屏截图**：截取鼠标所在屏幕。
- **文字提取 - AI 分析**：框选后交给配置的 AI 接口。
- **截图并翻译**：框选后识别、合并换行并逐段翻译。

AI 分析与截图翻译不占热键，只从菜单栏触发。

## 截图缩略图

框选保存、应用窗口截图、全屏截图这三种“保存型”截图完成后，除“已保存”提示外，还会在截图所在屏幕的右下角出现系统风格缩略图。

- 约 5 秒后淡出；鼠标悬浮在缩略图上时暂停计时，移开后继续。
- 最大 `180 × 120 pt`，按原比例缩放；多张缩略图在同一屏幕右下角向上堆叠，最新一张在最下面。
- 悬浮时四角显示操作：左上删除、右上关闭、右下在 Finder 打开、左下贴图；点图主体进入标注编辑器，并关闭缩略图。
- 删除会删除已保存文件、清空仍匹配的剪贴板图片并关闭缩略图；关闭只关缩略图；打开 Finder 和贴图后缩略图保留，继续按计时淡出。
- 滚动截图、OCR、AI、翻译仍使用原来的结果窗，不显示缩略图；截图并贴图直接进入贴图，也不显示缩略图。

## 标注截图

从菜单“标注截图”、截图缩略图的主体，或贴图左下角的标注按钮进入独立置顶的标注编辑器；画布底部是工具栏。没有标注全局热键。

- **多开**：每次标注打开独立窗口，可同时编辑多张截图；新窗口标题带编号并层叠错开，关闭一个不影响其他窗口。

- **工具**：选择、矩形、椭圆、箭头、直线、文字、序号、画笔、高亮、马赛克、模糊、色块、裁剪。默认工具是箭头。
- **样式**：默认红色，8 色可选；线宽 2/4/7 pt，文字 14/18/24 pt。高亮固定半透明黄色。
- **对象操作**：标注可选中、拖动、8 向缩放、删除；支持撤销/重做。
- **画布操作**：默认适应窗口；触控板捏合缩放，`⌘+` / `⌘-` 缩放，`⌘0` 适应窗口。
- **文字**：点击画布直接输入；`Return` 提交，`Option+Return` 或 `Shift+Return` 换行，`Esc` 提交。
- **裁剪与方向**：裁剪后可点“应用裁剪”；支持左右旋转 90°、水平翻转。已有标注会随画布同步变换，文字与序号保持正向可读。
- **隐私遮挡**：马赛克、模糊和纯黑色块都是固定强预设；编辑器内可撤销，点“完成/贴图”时烘焙成最终像素，输出文件不保留遮挡下的原内容。
- **完成**：复制到剪贴板并保存到 `~/Pictures/UDaSnap/`，只写一张最终 PNG，不保存原图。
- **贴图**：在复制、保存之后，再生成始终置顶的浮窗。

快捷键：`V` 选择、`R` 矩形、`O` 椭圆、`A` 箭头、`L` 直线、`T` 文字、`N` 序号、`P` 画笔、`H` 高亮、`M` 马赛克、`B` 模糊、`S` 色块、`C` 裁剪。

标注编辑器本身不接 OCR、AI、翻译，也不支持滚动长图标注；需要 OCR / AI / 翻译时请用贴图右侧的快捷按钮或菜单入口。

## 贴图浮窗

- 始终置顶，跨所有桌面空间。
- 拖动移动；拖动边缘或角点做 8 向缩放。
- 鼠标位于窗口上时滚轮等比缩放，以鼠标位置为锚点。
- 悬浮时四角出现操作：左上删除、右上关闭、左下标注、右下在 Finder 打开；点图主体仍是普通拖动，双击关闭。
- 右侧外部竖排提供“文字提取（OCR）”“文字提取-AI分析”“立即翻译”；它们复用贴图已保存的原图，不另存重复 PNG，贴图保持不动。
- 删除会删除已保存文件、清空仍匹配的剪贴板图片并关闭浮窗；关闭只关浮窗。
- 点左下角标注后，原贴图关闭，在贴图原来的位置附近按同一张图的正常标注页尺寸打开；完成只保存并复制新标注图，不自动重新贴图；取消不恢复原贴图，原图文件仍保留。
- 选中浮窗后按 `Delete`，关闭浮窗。

## 截图与保存

- 所有截图默认保存为原始像素 PNG。
- 保存目录：`~/Pictures/UDaSnap/`。
- 普通截图、窗口截图、全屏截图会同时写入剪贴板。
- 标注截图点“完成”后复制并保存最终 PNG；原图不另存。
- 滚动截图完成后会弹出只读长图预览，可缩放、滚动、复制。

## OCR 与 AI

- OCR 使用 macOS Vision，在本机完成，不联网。
- 文字结果可编辑、复制；工具栏可一键合并视觉换行，再点恢复逐行。
- AI 支持“文字提取”和“内容理解”两种模式，各自缓存当前结果、上一版和对话。
- “小U”对话按需展开，使用 SSE 流式输出，可随时停止。
- AI 设置支持 OpenAI 兼容接口、模型名、API Key 或免鉴权本地接口，以及三块可编辑提示词。
- API Key 只存 macOS 钥匙串；打开 AI 设置页不会自动读取，点“查看”才请求系统授权。

## 翻译

- 在 OCR 结果窗点“翻译”，整页送出，逐段返回。
- 源语言可选自动检测；目标语言可选简体中文、繁體中文、English、日本語、한국어。
- 方向可一键对换并全局记住；“恢复原文”清掉译文，回到翻译前文本。

## 隐私与数据

“偏好设置 → 隐私与数据”提供：

- 查看同意版本、数据位置、权限状态、当前 AI 接口。
- 打开截图目录、配置目录。
- 清除 API Key、清除应用配置。
- 清理 UDaSnap 截图，或设置 7 / 30 天自动保留。
- 撤回同意；撤回后停止截图和 AI 请求，关闭结果窗，回到同意页。

自动清理只删除符合 UDaSnap 命名规则的 PNG，不会碰你手动放进目录的其他文件。

## 常见问题

**截图是全黑或只有壁纸？**  
检查屏幕录制权限；授权后需要重启应用。如果系统设置里已显示 UDaSnap 打开但仍无效，可能是旧签名版本的残留条目：退出 UDaSnap，执行 `tccutil reset ScreenCapture com.udalink.udasnap`，重新打开应用并重新授权一次。从源码安装时 `build.sh install` 会用固定本地证书签名，后续 rebuild 不需要反复授权。

**热键没反应？**  
可能被其他应用占用。打开“强力模式”，或换一个组合键。

**滚动截图没有自动滚动？**  
自动滚动依赖辅助功能权限；未授权时可手动滚动，松手后继续拼接。

**AI 提示“未配置 Key”？**  
先确认接口需要鉴权；需要时在 AI 设置点“查看”，按系统提示授权钥匙串读取。

**预编译包打不开？**  
Release 中的包未使用 Developer ID 签名、未公证，Gatekeeper 会阻止。请从源码构建，或自行重新签名。
